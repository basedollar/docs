# Liquity's Bug Bounty

BaseDollar is built on Liquity V2's audited smart contracts. A bug bounty program for Liquity's underlying smart contracts is active.

Check out Liquity's [bug bounty](https://docs.liquity.org/v2-documentation/bug-bounty) program for the most up to date information.

The preferred way to submit a vulnerability is through Liquity's Vault on [Hats Finance](https://app.hats.finance/bug-bounties/liquity-0xd9a1751269d5506e3528241e3f35d3fbeb974b6b/rewards).

## Reporting a Vulnerability to Liquity

**Email**: security@liquity.org  
**Subject**: [SECURITY DISCLOSURE]

For sensitive vulnerabilities, encrypt the email using Liquity's PGP key (Fingerprint: D4BA B0E7 3B99 4FC5 79DC 9E0A C640 0C72 C5B8 CA28).
