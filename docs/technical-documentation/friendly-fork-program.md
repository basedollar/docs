# Liquity Friendly Fork Program

While extending Liquity's base protocol, we did not do it in the dark or in secret. Base Dollar was built in the open for everyone to see and with permission from the Liquity team. We are a "Friendly Fork" and chose to pay a small license fee to them.

When Liquity wins, Base Dollar wins. When Base Dollar wins, Liquity wins.
